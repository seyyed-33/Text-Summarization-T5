# 📝 Text Summarization with T5

This project uses **T5 (Text-to-Text Transfer Transformer)** to summarize long texts into short, concise summaries.

## 📊 Model
- **T5-small** from Hugging Face
- Pre-trained on various NLP tasks

## 🛠️ Technologies Used
- Python
- Transformers (Hugging Face)
- T5
